# 两段参考录屏的镜头观察

> 观察于 2026-10-28。引用会话提供三次 MP4 上传，但前两份的 SHA-256 完全相同，因此只有**两段独立作品**。下文 A、B 的时间均为手机录屏时间，约到 1 秒；播放器按钮、状态栏、进度条和第二段画面上下的大块黑边不属于作品设计。分析基于 5 秒通览和关键段落的 1 秒逐帧取样。没有源工程、逐词转写或独立原片，不能据此断言具体软件、镜头实现方式、精确剪辑帧或声音的逐词同步。

**使用边界：** A、B 是测试导演系统的案例，不是 GENCAN 的固定模板。它们的暗色、字体、配色、画幅、节奏和具体隐喻都不自动成为品牌规范。每期从主题、受众、证据和观众要理解的变化重新决定视觉语言；只有经新题材的动态分镜验证有效的做法才进入可复用镜头库。

## A：工作中断与找回思路

| 录屏时间 | 直接看到的结构与运动 | 可复用的导演动作 |
| --- | --- | --- |
| 0–13 秒 | 办公人物、工作台、电量和通知在不同构图中建立“被打断”的处境；人物与电量图标反复出现。约 3–4 秒从暖色工作场景换到冷色办公场景。 | 先让观众认出主角和处境，变化落在已有对象上。 |
| 13–23 秒 | 标题“三道尔原理”后，物理公式、旧式设备/人物画面相继出现；标题独立停留。 | 用停顿建立章节，再引入证据或机制。 |
| 30–47 秒 | 同一个任务板长期居中，四行任务逐步填入；通知“在吗？”挤入并占据第一行，随后行内内容被擦除。板和行的位置保持，主要运动发生在内容层。 | `in-place` 状态变换比换一张全新画面更能表达“覆盖/丢失”。 |
| 48–59 秒 | 黑底曲线、亮点、公式和强调环逐步叠加，图表坐标基本不动。 | 对抽象机制先留出读图时间，再逐层揭示。 |
| 65–88 秒 | 通知、人物、电量、任务板与存储格在数个场景中再现；存储格从空到满，任务板里出现“已保存”提示。 | 用可辨认的对象和位置重复，串起不同图解场景。 |
| 100–120 秒 | 人物拿手机与数据计数并置，随后切换到钓鱼隐喻；水面、浮标和计数在一个构图内持续变化。 | 一个视觉隐喻可以承载多句旁白，不必一句一镜。 |

**镜头与节奏观察：** A 的高频变化主要是任务卡、文字、计数、曲线和高亮；在 35–46 秒的任务板、48–59 秒的曲线以及 110–120 秒的浮标段，画面布局相对稳定。场景之间能看到硬切、模糊/淡入和颜色换场；取样不足以把每个变化判成相机推拉。人物、任务板、通知和电量的重复，比单一连续空间更明显地承担了跨段落的连续性。

## B：幸存者偏差与历史案例

| 录屏时间 | 直接看到的结构与运动 | 可复用的导演动作 |
| --- | --- | --- |
| 0–19 秒 | 猫坠落的剪影、急诊记录、样本数量和折线图依次出现。折线图约 10–18 秒保持相同坐标系，先画上升段，再出现末端急降与标注。 | 让证据在原位累积，再揭示反转；保持坐标系可比。 |
| 19–38 秒 | “幸存者偏差”标题居中停留，随后回到猫的图形和文字清单。 | 先命名概念，再用同一对象检验理解。 |
| 38–61 秒 | 年代标记、飞机编队与单架飞机示意交替；约 44–56 秒，飞机轮廓基本固定，弹孔、部位标注、倒数和解释在其上逐步添加。 | 在一张稳定图解上推进因果，不靠频繁运镜制造速度。 |
| 75–88 秒 | 人数与图表解释回到同一问题，末端曲线和高亮再次被指出，随后出现概念总结卡。 | 跨案例复用同一种“缺失样本”视觉逻辑。 |
| 89–102 秒 | 纪念墙/相框、引用文字和对照卡依次出现；每个画面给文字留了停留。 | 史料与抽象结论用不同视觉层级。 |
| 116–138 秒 | 1938 年地图路线、单机、山脉和机群分阶段接续；轨迹和飞机是章节之间的视觉线索。 | 跨不同世界可用图形母题与运动方向接续。 |

**镜头与节奏观察：** B 的主画面是横版，顶部日期/章名、底部整句字幕和金色重点词构成稳定版式。图表、飞机轮廓、地图弧线的原位增量变化很突出；取样显示多个长停留和近黑的章节过渡，不能把手机录屏的大块黑边算作视频的黑帧。没有证据表明整条片共用一个虚拟摄影机或对象实例。

## 两段放在一起看

| 维度 | 观察到的共同点 | 需要保留的差异 |
| --- | --- | --- |
| 视觉结构 | 暗背景、少量强调色、一个主要焦点、章节式叙事；图形和文字逐层出现。 | A 以竖屏人物/任务板为主，B 以横屏图表/历史示意为主。 |
| 相机与空间 | 构图停留为常态，局部强化时才改变尺度或位置；对象与图解的状态变化比持续推拉更重要。 | A 靠人物/道具重复建立熟悉感；B 靠图表坐标、飞机与路线的语义接续。 |
| 转场 | 都用标题或暗场划分章节，也用前后共享的图形/问题减少割裂。 | A 更常从工作处境切入机制图；B 更常在史料、图表和概念卡之间切换。 |
| 排版 | 重点词有独立颜色与节奏，字幕与主画面分层。 | A 多为上方大字，红色打断点；B 多为底部整句，金色关键词和日期。 |
| 声音 | 两份独立录屏都有 AAC 音轨，取样中也没有检测到超过 0.45 秒、低于 -32 dB 的长静音。 | 未获得可靠逐词转写，也未做听感评审；不能认定某一运镜、音效或字幕恰好卡在配音词或音乐拍点。 |

**推断，待用原片和人工听看确认：** 两段作品的声画设计可能以旁白语义单元驱动图形逐层显现；章节标题与反转处可能有声音强调。当前只确认视觉阶段的先后关系和音轨存在，不能把这些推断写成已验证的同步规则。

## 对 GENCAN v0.1 的校准

1. **保留 `FilmPlan` 为唯一时间依据。** `beat → world/object → shot → marker` 能表达两段片里“先建立概念，再局部揭示”的结构，也允许别的题材采用完全不同的画幅与风格。现在的 15 秒样片只验证单一世界的对象持续和相机连续；它不是对 A 或 B 的复刻，也不能代表完整作品节奏。
2. **优先实现原位状态变化和镜头停顿。** 先让同一图表/任务板在多句文案里持续存在，支持分层显现、擦除、计数和高亮。`CameraRig` 保留，但每次移动都应解释“观众要重新看哪里”。
3. **转场按内容关系选。** v0.1 已有连续相机和对象接力线。下一步应先补语义硬切/淡出与图形匹配；穿越和复杂形变等到具体故事需要时再做。参考片没有证明“五种转场全部必备”。
4. **允许多个 world 与跨世界视觉母题。** A/B 都跨工作处境、图表、历史场景。未来正式片需要在计划里记录世界入口/出口、共享符号、运动方向和观看焦点；不要强迫全片处在一个无限画布中。校验器已能记录跨世界的 `object-match`，但动态分镜尚无通用的跨世界匹配渲染器；同世界 `anchor-bridge` 仍负责可见对象接力。
5. **定稿配音后再锁同步。** `markers` 需增加配音词/句的真实时间、音效进入点和字幕区间；无声动态分镜只评结构与视觉节奏。自动 QA 检查时间空隙、遮挡、异常跳变；审美仍由人通看 10–15 秒样片。

| 优先级 | 产物 | 验证方式 |
