# 可选字体素材

以下文件从独立安装的 OpenMontage `e01dbf433f46eeb91d39bf905e194162921019a3` 中按原样选取，供每期根据内容选择；它们不是 GENCAN 的固定视觉风格。

| 文件 | 可用场景 | 原始来源与许可 |
| --- | --- | --- |
| `SpaceGrotesk-latin.woff2` | 英文标题、数字、界面标签 | [OpenMontage 字体目录](https://github.com/calesthio/OpenMontage/tree/e01dbf433f46eeb91d39bf905e194162921019a3/remotion-composer/src/fonts)，`SpaceGrotesk-OFL.txt`，SIL OFL 1.1 |
| `PlayfairDisplay-latin.woff2`、`PlayfairDisplay-Italic-latin.woff2` | 适合题材时的英文引语或章节标题 | 同上，`PlayfairDisplay-OFL.txt`，SIL OFL 1.1 |

字体与对应的 OFL 文本一起保留。它们仅包含拉丁文字子集，不负责中文旁白字幕；中文字体应在具体项目中另选并记录授权。使用前确认字形、字号和移动端可读性。不要把 OpenMontage 的标志、吉祥物或演示视频当成 GENCAN 的通用素材。
